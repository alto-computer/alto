Alto design system

Built on tools that already work: Radix Colors for every neutral and tint, shadcn/ui for components, lucide for icons. One thing is ours: the red thread.

Principles

  • One red thread. Red appears only where something connects you to the agent: the thread, a knot, the primary action, the focus ring.
  • Verified by default. Use Radix, shadcn and lucide as they ship. Change a default only when the change has a reason you can say in one line.
  • Calm on the surface. Warm grey ground, soft weights, lots of air. The busy work happens underneath and stays out of the way until you look.
  • Every detail means something. If an element has no reason, it does not ship.

Red is for

  • the thread and its knots
  • one primary button per view
  • active state fills and live status
  • focus rings

Red is not for

  • decoration or headings
  • errors: those use a darker, duller red (#a3231d) and always come with an icon and text, the way Airbnb keeps errors apart from its brand red
  • more than one loud thing per screen

Clew, the otter

Line

One thin black line, the same weight as the banner. Never thickened, never filled, never recoloured. In dark mode the line turns light.

Colour

The only colour allowed in a drawing is the thread. If there is no thread in the pose, there is no colour.

Size

72px or larger as a mark. Below 32px use the knot instead, since the face stops reading.

Poses

Each pose has a job: holding the thread (home), asleep with the thread tied on (harness), tugging the thread (interface), measuring with it (eval), peeking up (empty states).

Use it

The tokens live in ~/personal/alto-site/design/tokens.css. In a shadcn/ui app, import them in place of the generated theme.

npx shadcn@latest init        # pick "neutral", then replace the theme block
npm i lucide-react

/* app/globals.css */
@import "../design/tokens.css";
