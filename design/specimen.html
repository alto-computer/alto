Alto Computer · design system v2

Calm canvas, one red thread

The structure comes from Airbnb's Design Language System: a near-white canvas, one ink colour, hairline borders, soft corners, and a single saturated colour that appears in very few places. Airbnb's colour is Rausch. Ours is the thread. Components come from shadcn/ui and icons from lucide, used as they ship.

Principles

Airbnb's four, rewritten for an agent you can follow.

UnifiedOne threadEvery screen tells the same story: you are connected to the agent. If an element doesn't help tell it, it goes.
UniversalCalm by defaultNeutral canvas, plain words, readable contrast. Long-running work should never feel tense to look at.
IconicRed means "you"The only colour marks the one action that matters and the line back to you. Nothing else is red.
ConversationalAlways one glance awayStatus, sources and steering are visible without opening anything. The agent talks in small, plain updates.

The thread appears in exactly three places

Airbnb uses Rausch in three components: the main button, the search orb and the saved heart. We do the same.

The one action. One primary button per screen, never two.

Running · 2h 14m

The live agent. Something is working for you right now.

The thread. Knots and the line that ties the work back to you.

Focus rings are ink, errors use a darker red (#a3231d) with an icon, and success is green. None of them borrow the thread.
